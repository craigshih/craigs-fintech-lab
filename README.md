# Craig's FinTech Lab

政大金融科技創新實驗室成員 Craig 的金融科技學習基地：五大領域學習路徑、知識庫、筆記、職缺雷達、論文雷達。

- 公開網站：https://craigshih.github.io/craigs-fintech-lab/
- 本機完整版（含實驗室行事曆）：`python3 serve.py` 後開 http://localhost:8791

## 檔案
| 檔案 | 內容 | 更新方式 |
|---|---|---|
| `data/domains.js` | 五大領域學習路徑、課程、論文關鍵字 | 手動 |
| `data/library.js` | 知識庫（新聞、論文、白皮書、企業報告、監理文件的知識點） | 排程，每週二、六 |
| `data/jobs.js` | 職缺 | 排程，每週一、四 |
| `data/thesis.js` | 論文雷達（一魚兩吃） | 排程，每週一、三、五 |
| `data/events.js` | 實驗室行事曆（**私人，不上傳**） | 排程，每天 |

筆記與學習進度存在瀏覽器（localStorage），可在筆記區匯出 / 匯入備份。
